# USDA Ag Data Commons — datasets agrícolas abiertos

Repositorio USDA de datasets de suelos, cultivos, clima, manejo,
fenología y calidad de agua, en su mayoría de investigaciones
financiadas con fondos públicos.

**Para GrazePoint:** contexto agronómico del análogo EEUU —
experimento de rotación comparable, medición de suelo con metodología
publicada, curva de cosecha de la especie recomendada. Alimenta el
catálogo con datos de campo reales, no solo literatura.

**Se cruza con:** [[quickstats]] (estadística oficial), [[cropscape-cdl]],
[[web-soil-survey]]; el contraste NASA-satélite vs USDA-experimento es
exactamente el «Best Use of Data» del jurado.

**Acceso:** portal DKAN con API (`/api/1/metastore/schemas/dataset/items`).
Sin login para leer.
