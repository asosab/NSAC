# EarthExplorer — portal USGS de descarga

Buscador geográfico del USGS: escenas [[landsat]], tiles [[srtm]],
[[naip]], [[nlcd]] y más colecciones federales. Con login permite
descarga masiva; sin login, navegación y previsualización.

**Para GrazePoint:** vía de entrada a la precarga geográfica del
predio (elevación + historial Landsat). También sirve para el análogo
EEUU cuando toca comparar.

**Acceso:** portal con login USGS; hay clientes (`landsatxplore`,
`earthengine-api` con Earth Engine). No es API en vivo → herramienta
de precarga.
