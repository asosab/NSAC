# USDA AMS Market News — precios de commodities

Reportes de precio, demanda y oferta de cultivos y ganado en mercados
de EE.UU. API pública con key gratuita (`mymarketnews.ams.usda.gov`).

**Para GrazePoint:** responde la pregunta del agricultor «¿y esto a
quién se lo vendo?». Una rotación sin mercado local no es recomendación,
es un poema. En el análogo EEUU da precio semanal del cultivo sugerido;
en Bolivia queda como patrón de diseño para conectar ferias locales.

**Se cruza con:** [[quickstats]] (producción histórica vs precio
actual), [[cropscape-cdl]] (qué se siembra en la zona → competencia).

**Acceso:** API REST con key por email. Entra al router cuando haya
que rankear especies por viabilidad comercial.
